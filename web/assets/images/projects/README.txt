FOTOS DE PROYECTOS — INFA SOLUCIONES

Para que una foto aparezca en el caso de estudio correspondiente, guárdala en
la carpeta indicada y con el nombre exacto:

1. Metalmecánica
   Carpeta: metalmecanica
   Archivo: caso-metal.webp
   Aparece en el caso de Metalmecánica y soldadura.

2. Carpintería y melamina
   Carpeta: carpinteria
   Archivo: caso-muebles.webp
   Aparece en el caso de Carpintería y melamina.

3. Módulos y construcción
   Carpeta: modulos
   Archivo: caso-modulos.webp
   Aparece en el caso de Módulos y construcción.

No hay que modificar código para reemplazar o añadir esas tres fotos: conserva
la carpeta y el nombre indicados. Si falta un archivo, la web mantiene el
espacio de fotografía pendiente en vez de mostrar una imagen rota.

Para publicar fotos de hidráulica, mantenimiento, más proyectos o comparativas
de antes y después, primero hay que agregar el caso y sus datos en
web/js/content.js. Esta web no genera casos automáticamente por encontrar
archivos en una carpeta.

Recomendaciones:
- Usa fotografías reales del trabajo, con autorización del cliente.
- Prefiere WebP, orientación horizontal y un ancho de 1200 a 1600 px.
- Usa nombres en minúsculas, sin espacios ni tildes.
- No incluyas datos personales, documentos, placas o información confidencial.
